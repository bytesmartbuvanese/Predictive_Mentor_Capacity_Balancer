**To get StudentPrediction.csv from forcast_component.py use the below cammand**
uv run python -c "from forecast_component import MentoringDemandForecaster; from main import forecaster, read_student_dataset, prepare_model_features, dataset_identifiers; rows=read_student_dataset('engineered_data/student_course_features.csv'); ids,courses=dataset_identifiers(rows); result=forecaster.forecast(prepare_model_features(rows), student_ids=ids, course_codes=courses); MentoringDemandForecaster.export_student_predictions(result, 'StudentPredictions.csv')"


**To run mentor_managment.py**
uv run python mentor_management.py --students StudentPredictions.csv --mentors mentor_data.csv --output-dir mentor_management_outputs

**To include current mentor assignments, add:**
--existing-assignments current_mentor_assignments.csv
